## 💊 Pharmacy Sales Analysis Dashboard
## 📌 Project Description
This project analyzes pharmacy sales data using Tableau to understand sales performance, product behavior, and customer purchasing patterns.
The goal is to transform raw data into clear and interactive dashboards that support better business decisions.
📊 Dashboards Overview
## 🧾 1. Sales Analysis Dashboard
🌍 Total sales by region
📈 Monthly sales trends
🗂️ Sales by product category
💰 Average order value
🔄 Sales comparison across regions
## 💊 2. Product & Customer Analysis Dashboard
⭐ Best-selling and least-selling products
📦 Sales distribution by product category
📈 Profit analysis per product
👥 Top purchasing customers
🌍 Customer distribution by region
## 🛠️ Tools Used
📊 Tableau
📁 CSV / Excel Dataset
🐙 GitHub
✨ This project highlights my ability to analyze pharmacy data and present insights using interactive dashboards.
