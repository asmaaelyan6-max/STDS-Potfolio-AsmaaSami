## 📊 Project Description
This project focuses on analyzing sales data using SQL to extract meaningful insights that support business decision-making.
The main objective of the project is to explore sales performance, identify trends, and analyze key metrics such as total sales, revenue distribution, and customer behavior.
SQL queries were used to clean the data, filter records, perform aggregations, and generate summaries that answer important business questions.
This project demonstrates my ability to work with relational data, write efficient SQL queries, and translate raw data into actionable insights.
