## 📊 Sales Dashboard Project
## This project focuses on analyzing sales data and presenting key insights through an interactive dashboard. The main objective is to transform raw sales data into meaningful information by performing data cleaning, analysis, and visualization.
## 📈 The dashboard highlights important metrics such as sales performance, trends, and comparisons to support better decision-making.
## 🧹 Data preparation and cleaning were applied to ensure accuracy and consistency.
## 🎯 The final result is a clear, simple, and user-friendly dashboard that effectively tells a story using data.
