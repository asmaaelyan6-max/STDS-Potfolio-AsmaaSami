# 💼 Workforce Analytics Dashboard (Power BI)

## 📌 Project Description
The **Workforce Analytics Dashboard** project focuses on analyzing human resources data to extract meaningful insights into employee demographics, salary distribution, and attrition rates. Using **Power BI**, raw workforce data was transformed into an interactive dashboard to help HR managers make **data-driven decisions**.  

---

## 📊 Key Features & Visuals

### 🎯 KPIs
- **Total Employee Count:** 1,470  
- **Average Salary:** $112.96K  
- **Max/Min Salary**  
- **Average Age**  

### 👥 Demographics Analysis
- Breakdown of employees by **Gender**, **Ethnicity**, and **Marital Status**  

### 💰 Salary Insights
- Average salary trends analyzed by **Age**, **Gender**, and **Department**  

### 📉 Attrition Tracking
- Monitoring employee attrition by **Department** and **Years at the Company**  

### ⚖️ Work-Life Balance
- Analyzing **overtime patterns** across different job roles  

### 🛠️ Interactivity
- Advanced **slicers** added for **Department**, **Education Field**, **Marital Status**, and **Job Role**  

---

## 🚀 Outcome
This dashboard allows HR managers to quickly identify trends, make informed decisions on workforce planning, and improve employee retention strategies.
